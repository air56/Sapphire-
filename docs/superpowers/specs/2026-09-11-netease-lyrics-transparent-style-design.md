# 网易云歌词组件透明视觉预览设计

- 日期：2026-09-11
- 状态：待用户审查
- 范围：仅网页预览版；本阶段不修改正式组件的运行逻辑和安装包

## 1. 背景与目标

当前歌词组件的背景存在明显的矩形卡片感，与用户桌面左上角时钟插件的透明悬浮风格不一致。本设计先制作一个独立网页预览，用于确认透明歌词层、双语排版和中日英字体组合，确认后再进入正式组件实现。

目标：

1. 背景完全透明，歌词直接悬浮在桌面壁纸上。
2. 外文原文显示在上方，中文翻译显示在下方。
3. 双语歌词出现或消失时，下一句歌词的位置保持不变。
4. 中文、日文/假名、英文/拉丁文字分别支持字体选择。
5. 预览页可调节组件宽度、高度和歌词样式，便于确定最终方案。

## 2. 视觉方向：A — 极简透明文字层

### 2.1 容器

- 主歌词区域 `background: transparent`。
- 不使用大面积不透明背景、不使用明显矩形边框。
- 不使用常驻的亚克力卡片；透明效果由文字阴影和柔光保证可读性。
- 预览页面的设置栏可以使用独立的深色半透明面板，但设置栏不会进入最终组件。
- 组件尺寸由宽度和高度独立控制，不再固定为方形。

### 2.2 文字层

默认文字效果：

```css
text-shadow:
  0 2px 8px rgba(0, 0, 0, 0.45),
  0 0 2px rgba(255, 255, 255, 0.28);
```

- 当前歌词：高不透明度、较清晰的白色或用户指定颜色。
- 前后歌词：降低不透明度，保持可辨识但不抢占焦点。
- 翻译：比原文小一档，使用稍低不透明度的辅助颜色。
- 可调节阴影强度、柔光强度、主歌词颜色、普通歌词颜色和翻译颜色。

## 3. 双语歌词排版

每句歌词在预览中被建模为一个固定高度的 lyric slot，而不是让原文和翻译分别参与普通文档流布局。

```text
┌─────────────────────────┐
│ 原文歌词                 │
│ 中文翻译                 │
└─────────────────────────┘
```

无翻译时仍保留翻译行的高度：

```text
┌─────────────────────────┐
│ 普通中文歌词             │
│                         │
└─────────────────────────┘
```

约束：

- 每个歌词单元拥有固定的 `min-height` 或等价的网格行轨道。
- 原文和翻译在同一个歌词单元内垂直排列。
- 翻译显示/隐藏只改变翻译内容的可见性，不改变歌词单元高度。
- 歌词滚动以歌词单元为整体滚动，当前歌词定位在固定视觉焦点。
- 预览必须展示有翻译、无翻译和混合歌词，验证滚动时无跳动。

## 4. 字体系统

预览页面提供三组独立字体选择器：

1. 中文：只应用于汉字和中文标点。
2. 日文/假名：只应用于日文假名及日文排版字符。
3. 英文/拉丁：只应用于拉丁字母、数字和英文标点。

实现方式：

- 使用 CSS 字体栈按语言拆分文本片段。
- 预览阶段以可清晰辨识的开源字体占位，并保留字体名称、授权和文件路径字段。
- 正式组件阶段只打包许可证清晰的字体文件，不依赖外部 CDN 或系统网络。
- 字体文件未确认授权前不得直接加入正式安装包。

预览至少提供以下风格类别：

- 极简无衬线；
- 日系圆润；
- 细体艺术；
- 手写感；
- 现代几何；
- 霓虹显示（作为对照，不作为 A 方案默认效果）。

## 5. 预览页交互

预览页需要包含：

### 尺寸控制

- 宽度；
- 高度；
- 最大歌词宽度；
- 整体缩放；
- 横向对齐；
- 纵向对齐。

### 文字控制

- 主歌词字号；
- 翻译字号；
- 三种语言字体；
- 字重；
- 行距；
- 原文与翻译间距；
- 当前歌词颜色；
- 普通歌词颜色；
- 翻译颜色；
- 文字透明度；
- 阴影强度；
- 柔光强度。

### 歌词模拟

- 播放/暂停；
- 上一句/下一句；
- 自动滚动；
- 当前歌词高亮；
- 翻译开关；
- 显示时间轴。

预览页应提供“选择此样式”按钮，保存当前字体和视觉参数，方便后续正式组件实现。

## 6. 示例内容

预览使用包含中文、日文、英文和双语翻译的静态样例，不连接网易云、不读取本地隐私数据：

```text
もう一度だけ
再一次就好

静かな夜に咲いた
在寂静的夜晚绽放

優しい彗星
温柔的彗星

I will remember the light
我会记住那道光
```

## 7. 非目标

本阶段不做以下改动：

- 不修改网易云歌词识别协议；
- 不修改 Sapphire Bridge；
- 不修改正式组件的实时滚动逻辑；
- 不将未经授权的字体下载或提交到仓库；
- 不将预览设置栏打包进最终组件。

## 8. 验收标准

设计预览被认为可用于下一阶段的条件：

1. 透明页面能直接看到预览背景，不出现明显方形卡片。
2. 中、日、英三种字体可以独立切换，并且示例文字能直观看出差异。
3. 外文原文和中文翻译上下排列。
4. 切换翻译显示状态或滚动到不同歌词时，后续歌词位置不跳动。
5. 宽度和高度可以分别调整，组件不被限制为正方形。
6. 选择按钮可以记录当前视觉方案和字体组合。
7. 预览与正式组件代码边界清晰，未引入本地隐私数据或运行时网络字体依赖。
