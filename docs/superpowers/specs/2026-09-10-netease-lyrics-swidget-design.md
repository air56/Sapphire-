# 网易云双语歌词 SWidget 设计规格

**日期：** 2026-09-10
**状态：** 已确认，等待书面规格审查
**目标平台：** Windows 10 / Windows 11、Sapphire、网易云音乐桌面客户端

## 1. 目标与范围

构建一个可在 Sapphire 中运行的歌词桌面小组件。组件以苹果 Liquid Glass 为视觉方向，自动显示网易云音乐桌面客户端当前播放歌曲的逐行同步歌词；歌曲存在翻译歌词时，显示原文和中文翻译，并显示下一句低透明度预告。

首期交付包含两个独立单元：

1. **歌词小组件（SWidget）**：负责 Liquid Glass UI、响应式排版、配置和状态展示。
2. **Netease Lyrics Bridge（本机桥接程序）**：负责读取 Windows SMTC 全局媒体会话、匹配和缓存歌词、并通过仅本机访问的实时接口向小组件提供数据。

首期不修改 Sapphire 宿主源码，不读取网易云私有进程内存或内部缓存，也不提供歌词编辑、登录、云同步、多播放器支持或逐字 KRC 动画。

## 2. 用户体验与验收目标

用户打开网易云音乐桌面客户端并播放歌曲后，组件应自动识别当前歌曲，在取得歌词后随播放进度切换当前句。

- 默认是宽歌词条，推荐初始比例约为 5:1，但用户可以在 Sapphire 中自由调整宽度和高度。
- 当前句显示原文；存在翻译时，在原文下方显示中文翻译；没有翻译时不保留空白行。
- 当前句之后的第一条有效歌词作为预告显示，透明度低于当前句；最后一句时不显示预告。
- 用户可持久化设置当前歌词字号、最大歌词显示长度、主文字颜色和组件尺寸。
- 组件在未播放、桥接未启动、歌词加载、无歌词和网络失败等状态下提供简洁、可恢复的引导，不显示技术堆栈或上一首歌的残留歌词。

## 3. 架构和职责边界

### 3.1 SWidget：Liquid Glass Lyrics Widget

SWidget 使用 SWidget 的 HTML 渲染能力和 `SWebWidget.qml` 容器承载界面。其职责为：

- 呈现当前原文、翻译、下一句预告与歌曲状态；
- 根据实际可用宽高执行响应式排版和截断；
- 实现半透明亚克力、背景模糊、彩色环境光、内高光、描边和悬浮阴影；
- 提供并保存字号、最大显示长度和文字颜色设置；
- 订阅桥接服务的本机实时事件流，并显示明确的连接/错误状态。

SWidget 不直接读取网易云进程、内部缓存或 Windows SMTC，不直接访问远端歌词服务。这样可保持 UI 层稳定、可独立测试，并避免播放器更新导致小组件失效。

### 3.2 Netease Lyrics Bridge：本机辅助程序

Bridge 作为独立的 Windows 辅助进程，首期采用 .NET 8 Windows 应用和 Windows SMTC API。职责为：

- 订阅 Windows System Media Transport Controls（SMTC）全局媒体会话；
- 仅接受可识别为网易云音乐桌面客户端的会话；
- 读取并标准化曲目标题、艺人、专辑封面、播放状态、播放位置和总时长；
- 使用歌名、艺人和时长作为歌曲匹配依据，查询并缓存原文与中文翻译 LRC；
- 解析 LRC 时间戳，合并原文与翻译，并向本机客户端发布统一的实时状态；
- 处理缓存、失败重试、断线重连和迟到响应丢弃。

Bridge 不对局域网或互联网监听，不存储账户信息或完整播放历史。

### 3.3 本机通信边界

Bridge 仅绑定 `127.0.0.1`，使用 HTTP 获取初始快照，并使用 Server-Sent Events（SSE）持续推送后续变化。SWidget 的网络权限仅用于访问这个本机地址及 Bridge 所需的歌词查询路径；所有外部歌词请求由 Bridge 发起。

## 4. 标准数据模型与数据流

### 4.1 数据流

1. 网易云音乐在 Windows 中公开当前媒体会话。
2. Bridge 发现并订阅网易云 SMTC 会话，获取元数据、播放状态和时间轴。
3. Bridge 为每次切歌创建新的 `trackSessionId`，用歌曲标题、艺人和时长查询本地歌词缓存；缓存未命中时查询歌词来源。
4. Bridge 解析原文与翻译 LRC，并以时间戳将翻译关联到原文行。
5. Bridge 通过本机 HTTP/SSE 发送完整快照和增量更新。
6. SWidget 保留最新会话的数据，按照桥接时间轴选择当前歌词、翻译和下一句，并更新视觉高亮。

### 4.2 状态快照

每个完整快照至少包含以下字段：

```text
trackSessionId
track: { title, artists, album?, artwork?, durationMs }
playback: { state: playing | paused | stopped, positionMs, updatedAt }
lyrics: {
  status: loading | ready | unavailable | error,
  lines: [{ startMs, original, translation? }]
}
bridge: { status: connected | waitingForPlayer | error, errorCode? }
```

`updatedAt` 是 Bridge 写入 `positionMs` 时的时间。SWidget 在 `playing` 状态下以本地单调时钟从该点平滑补间；`paused` 和 `stopped` 状态冻结位置。收到新的 SMTC 时间轴、拖动、暂停、恢复或切歌事件时，SWidget 以新快照立即校正位置。

### 4.3 歌词同步规则

- 当前行是 `startMs <= positionMs` 的最后一条有效歌词行。
- 下一句是当前行之后第一条具有非空原文的歌词行。
- 翻译按原文时间戳关联；翻译为空或不存在时，UI 不渲染翻译区域。
- Bridge 切歌时立即发布新的 `trackSessionId` 和加载状态。SWidget 收到不同会话标识后先清空旧歌词内容，再等待新会话的歌词，杜绝串歌闪现。
- 与旧 `trackSessionId` 关联的歌词请求结果或延迟事件一律丢弃。

## 5. 响应式布局与视觉设计

### 5.1 尺寸行为

组件不锁定固定宽高。默认宽歌词条约为 5:1；用户拖动后，布局根据可用空间变化：

- **空间充足：** 当前原文、翻译和下一句预告保持清晰层级，并可在水平方向获得更宽松的排布。
- **宽度变窄：** 原文、翻译和预告改为纵向层次；文本可在合理位置换行。
- **高度不足：** 先隐藏下一句预告，再压缩行距；当前原文和已有翻译优先保留。
- **极窄尺寸：** 原文和翻译分别换行；超出最大显示长度的内容按配置省略，绝不溢出边框。

字号采用用户设定的主字号。翻译与预告以固定比例从主字号派生，避免组件尺寸拉伸时出现比例失衡。

### 5.2 Liquid Glass 风格

视觉应呈现苹果风格的精致玻璃材质，同时保证可读性：

- 半透明亚克力底材和背景模糊；
- 细半透明描边、圆角和内高光；
- 微弱蓝紫粉色环境光和立体悬浮阴影；
- 当前歌词使用最高对比度；翻译和预告使用由主文字颜色派生的较低透明度；
- 当背景使文字对比不足时，增加轻微文字阴影或底材不透明度以保持可读性。

### 5.3 持久化设置

设置保存在组件本地，重新加载 Sapphire 或重启 Bridge 后仍保留：

| 设置 | 行为 |
| --- | --- |
| 歌词字号 | 控制当前原文主字号；翻译和预告按比例缩放。 |
| 最大歌词显示长度 | 限制单行的最大显示字符数；超出时依据可用空间换行或省略。 |
| 文字颜色 | 设定当前原文的主色；翻译与预告自动从该色派生透明度。 |
| 组件尺寸 | 保存用户最后一次调整后的宽度和高度。 |

首期不提供玻璃颜色、阴影、模糊强度等高级外观开关，避免增加不必要的设置复杂度。

## 6. 状态、错误与降级体验

| 触发情况 | Bridge 行为 | SWidget 显示与恢复 |
| --- | --- | --- |
| Bridge 未启动或断开 | 本机服务不可用 | 显示“等待歌词桥接服务”；定时自动重连，恢复后自动订阅。 |
| 未检测到网易云播放 | 进入 `waitingForPlayer` | 显示“打开网易云并播放歌曲”；不显示旧歌歌词。 |
| 切歌或歌词加载中 | 发布新会话及 `loading` | 清空旧歌词，显示“正在获取歌词”，准备好后原子替换。 |
| 网络查询暂时失败 | 优先读取缓存，按退避策略重试 | 保持加载或简洁失败提示；后续歌曲继续正常查询。 |
| 当前歌曲无歌词 | 发布 `unavailable` | 显示“当前歌曲暂无可用歌词”。 |
| 仅无翻译 | 正常提供原文行 | 显示原文，不显示空翻译行。 |
| 歌词匹配不确定 | 不采用低置信度结果 | 降级为无歌词状态，不显示可能属于另一首歌的文本。 |

## 7. 测试与验收

### 7.1 单元测试

- LRC 时间戳解析、排序、空行过滤和边界时间定位；
- 原文与翻译按时间戳合并；
- 下一句查找、最后一句隐藏与无翻译处理；
- 歌词最大长度、换行/省略决策与配置序列化；
- Bridge 的会话切换、缓存命中/失效、延迟响应丢弃与播放状态转换。

### 7.2 集成测试

- 使用模拟 SMTC 数据验证播放、暂停、恢复、拖动、切歌和时间轴校准；
- 验证 Bridge HTTP 初始快照和 SSE 更新的事件顺序；
- 验证 Bridge 重启、网络失败、歌词超时、SWidget 断线后自动重连；
- 验证服务仅绑定回环地址，局域网地址不可访问。

### 7.3 UI 验证

- 宽歌词条、窄高组件和极窄组件的视觉与文字不溢出；
- 原文+翻译、仅原文、无歌词、加载、未启动 Bridge 和重连状态；
- 字号、最大显示长度、文字颜色和尺寸重启后仍正确恢复；
- Liquid Glass 材质在常见浅色/深色桌面背景下保持可读性。

### 7.4 实机验收

在 Windows 10 和 Windows 11 上，使用网易云音乐桌面客户端验证：自动识别歌曲、逐行同步、翻译显示、切歌、暂停、拖动、Bridge 重启恢复，以及自由调整组件宽高。

## 8. 非功能要求

- 所有小组件到 Bridge 的通信仅限本机回环地址。
- Bridge 以缓存优先策略减少重复歌词请求；网络不可用时不阻塞媒体状态更新。
- UI 对歌词延迟、SMTC 临时不可用和 Bridge 重启具备自动恢复能力。
- 错误信息对用户使用简洁中文说明；详细诊断信息只进入 Bridge 本地日志。
- 首期系统只针对 Windows 10/11 与网易云音乐桌面客户端验收。
